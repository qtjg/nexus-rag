# Changelog

This repository follows a source-package release record. Hosting, cloud resources, credentials, and production activation are intentionally outside these entries.

## 1.1.0 — Git intelligence upgrade

NEXUS RAG now supports organization- and collection-scoped repository snapshot registration and submitted Git-diff review. Snapshot content is bounded, treated as untrusted source evidence, and never cloned or executed. Reviews retain structured, cited findings with deterministic safeguards; optional server-side AI assistance uses strict structured output and degrades safely to deterministic evidence when unavailable.

This release also adds Git-intelligence tests, example workflows, and the repository governance artifacts introduced during the source-package hardening work.

## 1.0.0 — Verified NEXUS RAG source handoff

Initial GitHub source-package handoff with grounded RAG, durable ingestion, organization governance, evaluation evidence, guarded enterprise controls, tests, CI, and GitHub maintenance documentation.
